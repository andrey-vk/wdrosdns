# Политика конфиденциальности

🇬🇧 [English version](PRIVACY.md)

**MikroTik DNS Helper** не собирает, не передаёт и не продаёт какие-либо пользовательские
данные разработчику или третьим лицам. Телеметрия, аналитика и удалённое логирование
отсутствуют полностью.

## Что сохраняется

Расширение сохраняет следующее локально в вашем браузере через `chrome.storage.local`:

- Профили подключения к RouterOS: адрес, логин, пароль и настройки DNS по умолчанию для
  каждого профиля, которые вы задаёте.
- Настройки расширения и параметры фильтров сборщика сетевых доменов.

`chrome.storage.local` — это локальное хранилище устройства. Расширение **не** использует
`chrome.storage.sync`, поэтому эти данные не синхронизируются через учётную запись браузера
и никогда не отправляются никуда, кроме как напрямую на настроенное вами устройство RouterOS.

Собранные метаданные сетевых запросов хранятся в `chrome.storage.session` и удаляются
браузером при его закрытии. Они нужны только для того, чтобы сборщик не терял собранное,
когда Manifest V3 выгружает service worker расширения при простое.

### О хранении пароля

Пароли RouterOS хранятся **без шифрования**. Хранилище расширений браузера не является
защищённым хранилищем учётных данных: его может прочитать любой, у кого есть доступ к
каталогу профиля браузера или к машине во время вашего сеанса. Для расширений браузера это
обычная ситуация, но о ней стоит сказать прямо.

Рекомендуется: завести в RouterOS отдельного пользователя для этого расширения — с правом
читать system identity и менять DNS, и ничего больше.

В собственной диагностике расширения (просмотр «ответ роутера» и подсказки статуса) пароли
маскируются, поэтому они не утекут при копировании результата.

## Что передаётся и кому

Единственные сетевые запросы, которые делает расширение, — это запросы напрямую из вашего
браузера к настроенным вами эндпоинтам REST API RouterOS (вашему собственному роутеру, в
вашей собственной сети). Эти запросы содержат логин/пароль, сохранённые для данного профиля,
и DNS-записи, которые вы решаете добавить. Ни один запрос никогда не отправляется
разработчику или на сторонний сервер.

Разрешение `webRequest` используется только для чтения метаданных запросов, сделанных
текущей вкладкой, полностью в пределах вашего браузера, чтобы заполнить сборщик сетевых
доменов. Сохраняются только имя хоста, метод запроса, тип ресурса, тайминги и
HTTP-статус/ошибка — полные URL отбрасываются сразу, поэтому строки запроса и содержащиеся
в них параметры не сохраняются вообще. Эти метаданные остаются в сессии браузера и покидают
её только в виде тех доменных имён, которые вы явно решили добавить на роутер.

## Третьи стороны

Отсутствуют. У расширения нет внешних зависимостей времени выполнения, рекламных сетей или
аналитических SDK.

В состав расширения входит статическая копия [Public Suffix List](https://publicsuffix.org/)
(лицензия Mozilla Public License 2.0) — она используется офлайн для определения регистрируемого
домена по имени хоста. Во время работы расширение не обращается за ней в сеть.

## Изменения

Любые изменения этой политики будут отражены в этом файле и в истории версий расширения в
данном репозитории.
